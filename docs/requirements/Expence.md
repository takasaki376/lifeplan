# 支出管理機能 要件

## 1. 基本機能

- ユーザーごとに支出データを登録・編集・削除できること
- 支出データはクラウド（Firestore等）に保存されること
- 支出データの取得・登録・更新・削除は認証済みユーザーのみ可能であること

## 2. 支出データの項目

- 支出ID（自動採番またはFirestoreのドキュメントID）
- 支出のカテゴリ（例：食費、住居費、交通費、教育費、医療費、娯楽費、その他）
- 金額（数値、必須）
- 詳細（任意：内容や備考など）
- 記録日（必須、日付型）
- 作成日時・更新日時（自動記録）

## 3. UI要件

- 支出一覧をテーブルまたはカード形式で表示すること
- 支出の追加・編集フォームを提供すること
  - 支出カテゴリはプルダウンで選択
  - 金額は数値入力
  - 詳細はテキスト入力（任意）
  - 記録日は日付入力
- 編集ボタンで既存支出の編集ができること
- 削除ボタンで支出を削除できること
- ローディング中はローダーを表示すること
- エラー発生時はエラーメッセージを表示すること

## 4. バリデーション

- 支出カテゴリは必須
- 金額は0より大きい数値で必須
- 記録日は必須
- 入力値に不備がある場合はエラーメッセージを表示

## 5. コード・API設計

- 型定義（TypeScript）を利用し、支出データの型安全性を担保
- API経由でCRUD操作を行う
- APIは認証トークン（Authorizationヘッダー）を検証し、ユーザーごとにデータを分離
- Firestore保存時はcreatedAt/updatedAtをTimestampで記録し、取得時はDate型に変換

## 6. その他

- Mantine UIを利用したユーザーインターフェース
- スマートフォン・PC両対応のレスポンシブデザイン
- 支出カテゴリは定数で管理し、日本語名称で表

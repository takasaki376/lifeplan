# 負債管理機能 要件

## 1. 基本機能

- ユーザーごとに負債データ（債務）を登録・編集・削除できること
- 負債データはクラウド（Firestore等）に保存されること
- 負債データの取得・登録・更新・削除は認証済みユーザーのみ可能であること

## 2. 負債データの項目

- 負債ID（自動採番またはFirestoreのドキュメントID）
- 債務名（例：住宅ローン、教育ローン、カードローンなど）
- 残高（数値、必須）
- 金利（%）
- 返済期日（日付、必須）
- 月額返済金額（数値、必須）
- 登録時点の日付
- 作成日時・更新日時（自動記録）

## 3. UI要件

- 負債一覧をテーブルまたはカード形式で表示すること
- 負債の追加・編集フォームを提供すること
  - 債務名はテキスト入力
  - 残高・金利・月額返済金額は数値入力
  - 返済期日は日付入力
- 編集ボタンで既存負債の編集ができること
- 削除ボタンで負債を削除できること
- ローディング中はローダーを表示すること
- エラー発生時はエラーメッセージを表示すること

## 4. バリデーション

- 債務名は必須
- 残高・月額返済金額は0より大きい数値で必須
- 金利は0以上の数値
- 返済期日は必須
- 入力値に不備がある場合はエラーメッセージを表示

## 5. コード・API設計

- 型定義（TypeScript）を利用し、負債データの型安全性を担保
- API経由でCRUD操作を行う
- APIは認証トークン（Authorizationヘッダー）を検証し、ユーザーごとにデータを分離
- Firestore保存時はcreatedAt/updatedAtをTimestampで記録し、取得時はDate型に変換

## 6. その他

- Mantine UIを利用したユーザーインターフェース
- スマートフォン・PC両対応のレスポンシブデザイン
- 負債の種類は定数で管理し、日本語名称で表示（必要

# 収入管理機能 要件

## 1. 基本機能

- ユーザーごとに収入データを登録・編集・削除できること
- 収入データはクラウド（Firestore等）に保存されること
- 収入データの取得・登録・更新・削除は認証済みユーザーのみ可能であること

## 2. 収入データの項目

- 収入ID（自動採番またはFirestoreのドキュメントID）
- 家族メンバーID（収入の所有者を識別）
- 収入の種類（例：給与、事業収入、年金、その他）
- 開始年齢・終了年齢（収入が発生する期間）
- 月額収入（数値、必須）
- 詳細（任意：会社名、収入の説明など）
- 作成日時・更新日時（自動記録）

## 3. UI要件

- 収入一覧をテーブルまたはカード形式で表示すること
- 収入の追加・編集フォームを提供すること
  - 収入の種類はプルダウンで選択
  - 月額収入は数値入力
  - 詳細はテキスト入力（任意）
  - 開始年齢・終了年齢は数値入力
- 編集ボタンで既存収入の編集ができること
- 削除ボタンで収入を削除できること
- ローディング中はローダーを表示すること
- エラー発生時はエラーメッセージを表示すること

## 4. バリデーション

- 収入の種類は必須
- 月額収入は0より大きい数値で必須
- 開始年齢・終了年齢は必須かつ妥当な範囲
- 入力値に不備がある場合はエラーメッセージを表示

## 5. コード・API設計

- 型定義（TypeScript）を利用し、収入データの型安全性を担保
- API経由でCRUD操作を行う
- APIは認証トークン（Authorizationヘッダー）を検証し、ユーザーごとにデータを分離
- Firestore保存時はcreatedAt/updatedAtをTimestampで記録し、取得時はDate型に変換

## 6. その他

- Mantine UIを利用したユーザーインターフェース
- スマートフォン・PC両対応のレスポンシブデザイン
- 収入の種類は定数で管理し、日本語名称で表

# 資産管理機能 要件

## 1. 基本機能

- ユーザーごとに資産データを登録・編集・削除できること
- 資産データはクラウド（Firestore等）に保存されること
- 資産データの取得・登録・更新・削除は認証済みユーザーのみ可能であること

## 2. 資産データの項目

- 資産ID（自動採番またはFirestoreのドキュメントID）
- 資産の種類（例：現金、預金、不動産、株式、その他）
- 詳細（任意：銀行名、不動産の所在地など）
- 金額（数値、必須）
- 作成日時・更新日時（自動記録）

## 3. UI要件

- 資産一覧をテーブルまたはカード形式で表示すること
- 資産の追加・編集フォームを提供すること
- 資産の種類はプルダウンで選択
- 金額は数値入力
- 詳細はテキスト入力（任意）
- 編集ボタンで既存資産の編集ができること
- 削除ボタンで資産を削除できること
- ローディング中はローダーを表示すること
- エラー発生時はエラーメッセージを表示すること

## 4. バリデーション

- 資産の種類は必須
- 金額は0より大きい数値で必須
- 入力値に不備がある場合はエラーメッセージを表示

## 5. コード・API設計

- 型定義（TypeScript）を利用し、資産データの型安全性を担保
- API経由でCRUD操作を行う
- APIは認証トークン（Authorizationヘッダー）を検証し、ユーザーごとにデータを分離
- Firestore保存時はcreatedAt/updatedAtをTimestampで記録し、取得時はDate型に変換

## 6. その他

- Mantine UIを利用したユーザーインターフェース
- スマートフォン・PC両対応のレスポンシブデザイン
- 資産の種類は定数（assetTypes）で管理し、日本語名称で表示
